# Task A1_1 — Цели и область SDK

## Цель
Зафиксировать scope v1.1: Server+Cloud, параллельные run’ы, outputs по settings, файлы как `FileInput`, селекторы как основной механизм патча.

## Объём работ
- Обновить терминологию и список требований в README.
- Явно прописать “не делаем в v1”.
- Зафиксировать допущения и ограничения (selector requireSingle, cancel = stop waiting).
- Зафиксировать path синтаксис: dot + массивы `[]`.
- Зафиксировать, что ошибки патча ловим на генерации.

## Критерии приёмки
- README-ТЗ.md и README-ТЗ-подробно.md содержат актуальные требования.
- Есть отдельный блок «Допущения».
- Ясно описано, где живут секреты (не в settings).

## Как проверить
- Открыть README и убедиться, что все пункты из ответов пользователя отражены.
- Проверить, что нигде не обещаем “авто‑interrupt при Cancel”.
