# Task C1_2 — Генератор классов параметров

## Цель
Сгенерировать типизированные классы параметров из settings spec.

## Объём работ
- CLI: `comfysdk-gen --workflow ... --settings ... --out ...`.
- Генерировать .cs: свойства с XML-docs.
- Поддержка nullable/required.
- Для file параметров тип = `FileInput`.
- Генератор валидирует селекторы и path (ошибка на этом этапе).

## Критерии приёмки
- Генерятся компилируемые классы.
- Если селектор/путь невалидны — генератор падает с объяснением.
- Имена классов по имени файлов.

## Как проверить
- В sample workflow специально сломать path → увидеть ошибку генерации.
- Скомпилировать generated код в samples.
