# Task D1_1 — Samples и Cookbook

## Цель
Сделать примеры, чтобы пользователь не страдал и не орал в монитор.

## Объём работ
- Sample: Server basic run.
- Sample: Cloud run (ApiPrefix, Bearer).
- Sample: Parallel runs (2-3 одновременно).
- Sample: FileInput (url+path).
- Cookbook: типовые рецепты и анти‑грабли (redirect, ws reconnect, outputs selection).

## Критерии приёмки
- Все samples компилируются и запускаются.
- В README есть команды запуска.
- Cookbook покрывает основные кейсы.

## Как проверить
- Запустить samples локально.
- Прогнать хотя бы один workflow end-to-end.
