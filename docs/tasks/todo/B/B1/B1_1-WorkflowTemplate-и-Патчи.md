# Task B1_1 — WorkflowTemplate и патчи

## Цель
Сделать модель шаблона workflow + систему патчей на основе NodeSelector + path.

## Объём работ
- Модель `WorkflowTemplate` (raw json + индекс узлов).
- `NodeSelector` (class_type + whereInputExists/value).
- Патчи: set value по path.
- path синтаксис: `a.b[0].c`.
- Генераторная валидация: patch должен примениться ровно к одному узлу (по умолчанию).

## Критерии приёмки
- Selector — основной; nodeId опционально.
- Если матчей != 1 → ошибка.
- Патчинг корректно меняет JSON.
- Поддержаны массивы `[]` в path.

## Как проверить
- Юнит-тест: workflow с двумя одинаковыми нодами → ошибка.
- Юнит-тест: патч в массиве работает.
