# Task C1_1 — Settings Spec v1

## Цель
Сделать JSON схему настроек, описывающую параметры, селекторы, патчи, outputs и версию.

## Объём работ
- Определить `settingsSchemaVersion: 1`.
- Описать параметры: name/type/selector/path/required/default/description.
- Описать file параметры: как конвертятся.
- Описать outputs блок.
- Описать diagnostics блок (save materialized workflow).
- Валидатор spec (минимально).

## Критерии приёмки
- Есть пример settings файла.
- Версия проверяется.
- Валидатор выдаёт понятные ошибки.

## Как проверить
- Прогнать генератор на валидном settings → ок.
- Поменять версию → ошибка с сообщением.
