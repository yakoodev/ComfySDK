# Tasks (для агента)

Структура:
- `tasks/todo/**` — актуальные задачи.
- `tasks/inProgress/**` — агент переносит сюда текущую.
- `tasks/completed/**` — агент переносит сюда после выполнения (с PR/commit ссылкой).

Правила:
- Каждая задача = отдельный PR/ветка (если удобно).
- В конце задачи агент add/обновляет docs и оставляет короткий отчёт в описании PR:
  - что сделано
  - как проверить
  - где смотреть sample

Никакой магии: если генератор не может применить patch — он падает на генерации. Лучше пусть упадёт сразу, чем потом “почему Comfy молчит”.
